# Research: Existing evaluation corpora for Paper T-Rail issue #86

## Summary

No permission-documented, human-adjudicated corpus found can satisfy issue #86 as-is: none jointly covers bibliography contamination from source documents, false/correct reference identities, and the exact legal/acquired file asset across English disciplines and articles, conference papers, preprints, books, and chapters. The best existing pieces are complementary: CEX for manually annotated PDF bibliography extraction (subject to file-level permission checks), Crossref’s 2,000-reference set for human-checked DOI matching, and DC3 for paper-version conflation; none establishes a representative population or gold labels for the exact file acquired by this application. These can inform a user-selected, permission-audited, paper-disjoint set, not replace its adjudication.

## Findings

1. **CEX is the closest source-document extraction component, not the full issue corpus.** Its Zenodo record describes 112 documents, TEI reference annotations, and a corrected original 56-document set plus 56 manually annotated PDFs; the record declares CC BY 4.0 for the dataset. It says PDFs marked “Restricted” are not distributed, while open-access PDFs are. This dataset-level declaration does not establish reuse terms for every included PDF; verify file-level permissions for each selected PDF before reuse. A 2026 benchmark paper describes CEX as English journal articles spanning 27 SCImago subject categories (1,581 pages and 5,160 references). It can benchmark reference-boundary/field extraction on those papers; it does not label citation-to-target identity, legal retrieval location, or which acquired bytes are the correct asset. The public record does not specify independent double annotation or adjudicator agreement. **Sources:** [CEX Zenodo record](https://zenodo.org/records/10535653); [Zhu et al., benchmark paper](https://ceur-ws.org/Vol-4187/full-02.pdf). **Support:** direct evidence for size, the dataset-level license declaration, manual annotations, and stated scope; inference for its fit as an extraction component. **Confidence:** high.

2. **GROBID end-to-end evaluation pairs actual PDFs with structured publisher gold, but is domain-narrow and not an adjudicated identity benchmark.** Its documentation describes roughly 5,927 papers from PMC, bioRxiv, PLOS, and eLife, with PDFs paired to NLM/JATS gold XML; the archive/Hugging Face card states CC-BY terms and identifies supplementary manual GROBID-team edits. This supports component evaluation of PDF-to-bibliography extraction and parsing on biomedical journal articles and bioRxiv preprints. Most reference gold is publisher XML (bioRxiv’s NLM was manually created); the team’s described manual reviews/additions concern other annotations, not independent adjudication of reference identities or acquired assets. The docs explicitly warn that some references are encoded only as raw strings and that gold XML can omit information, so parser scores can misclassify valid output. It includes no conference, book, or chapter source-document cohorts and has no predefined paper-disjoint split. **Sources:** [GROBID end-to-end evaluation docs](https://grobid.readthedocs.io/en/latest/End-to-end-evaluation/); [official dataset card](https://huggingface.co/datasets/sciencialab/grobid-evaluation); [Zenodo archive](https://zenodo.org/records/7708580). **Support:** direct evidence. **Confidence:** high.

3. **Crossref’s set is the strongest existing reference-identity component.** Crossref reports 2,000 real unstructured references sampled from Crossref metadata. A target DOI or null was assigned by checking matcher outputs and/or manual searching; the paper reports wrong-DOI and no-match cases, including errors that confused a book with a chapter or conference proceedings with a thesis. The public evaluation file includes a `source_DOI` for the citing work and a `gt` target, so references can be grouped by source DOI to construct a paper-disjoint split. The file is not a PDF corpus: it cannot evaluate extraction contamination, provider-output provenance, or whether the correct DOI produced the exact permitted file that the application acquired. The report does not give language, source-publication-type, or disciplinary subgroup denominators, and its scope is DOI matching for this Crossref-derived sample—not all references or all scholarly publications. Crossref says its metadata is open for unrestricted reuse; the repository’s MIT license is for the evaluation software and should not be misread as a license on third-party full text. The article-level split is feasible from `source_DOI`, but no official split is supplied and same-work/version grouping still needs checking. **Sources:** [Crossref evaluation report](https://www.crossref.org/blog/reference-matching-for-real-this-time/); [evaluation repository/data](https://github.com/CrossRef/reference-matching-evaluation/tree/master/analyses/3_unstructured_real_evaluation/data); [Crossref metadata reuse](https://www.crossref.org/services/metadata-retrieval/). **Support:** direct evidence for manual target assignment, documented errors, DOI-level task and source DOI field; interpretation for split feasibility. **Confidence:** high.

4. **LinkedBooks supplies genuinely human-annotated long-form humanities references, with sharply limited generalization.** Its data paper says 40,000+ manually annotated references from Venice historiography, from monograph reference lists and journal footnotes; it records source document IDs, and reports CC BY 4.0. Only annotated text lines are distributed (not the source books’ full text), and the paper says there was no double-keyed annotation subset. The corpus is multilingual and strongly localized to Venice history, not an English, all-discipline sample. Labels segment/classify references; a lookup module is described as a downstream function, not gold identity/asset labels. The original token/annotation split is not documented as document-disjoint. Whole source monographs/issues can in principle be grouped using the supplied document IDs, but this requires a new split and still cannot test extraction from full PDFs or exact acquired assets. **Sources:** [LinkedBooks data paper](https://openhumanitiesdata.metajnl.com/articles/10.5334/johd.9); [official annotation repository/schema](https://github.com/dhlab-epfl/LinkedBooksReferenceParsing). **Support:** direct evidence; interpretation for split feasibility. **Confidence:** high.

5. **RenoBench is a useful open parsing resource, but its labels are not human adjudication.** Its dataset card declares CDLA-Permissive-1.0 and describes 10,000 plain-text references matched to publisher-provided JATS annotations. Its pipeline extracts citations with an LLM, matches them using an edit-distance threshold, and applies automated checks. It reports 32% English; publication-type percentages (including books and conference proceedings) describe cited references, not a balanced set of full citing papers. The schema has `citing_article_doi`, which may be null, but provides no PDF input; its only split is `train`. DOI grouping could support a custom split for known citing papers, but null IDs and multiple versions need separate resolution. Publisher XML labels and automated matching are useful supervision, not proof of independently checked field/identity correctness. **Source:** [official RenoBench dataset card and README](https://huggingface.co/datasets/public-knowledge-project/ref-annotation-benchmark). **Support:** direct evidence. **Confidence:** high.

6. **DC3 informs same-work/version deduplication, not exact acquired-asset correctness.** The authors describe 3,286 clusters of 7,191 S2ORC papers, with candidate near-duplicates manually verified using metadata and PDFs when needed; the corpus targets versions of a paper. This is relevant to keeping preprint/conference/journal variants together for splits and examining false conflations. It does not label the “right” legal location or exact downloaded file/checksum, and its document-type/language strata do not establish issue-wide coverage. The linked repository has no visible dataset-specific license declaration; the study uses the 2020 S2ORC release, while the current S2ORC README says that old release is no longer supported and directs users to a continuously rebuilt API bulk dataset requiring an API key. Therefore, do not reuse DC3/S2ORC data without resolving dataset permissions and snapshot access. If independently cleared, cluster-wise splitting is feasible; the paper supplies no standard held-out partition. **Sources:** [Wu et al. (2022), primary study](https://www.cs.odu.edu/~jwu/downloads/pubs/wu-2022-doceng/wu-2022-doceng.pdf); [study repository](https://github.com/lamps-lab/docconflation); [S2ORC access/license notes](https://github.com/allenai/s2orc). **Support:** direct evidence for manual verification, clusters, and access notes; inference for using clusters as split groups. **Confidence:** high.

7. **Work/version relations are not asset labels.** Crossref’s schema allows relationships such as `isPreprintOf`, `isVersionOf`, `isPartOf`, and `isIdenticalTo`; arXiv’s API identifies submitted versions (e.g., `v1`, `v2`) and links to a PDF. These identifiers help design adjudication fields, but are metadata relationships/identifiers, not a human-labeled judgment that a specific retrieved, license-eligible file is the exact acceptable asset. **Sources:** [Crossref relationship schema](https://www.crossref.org/documentation/schema-library/markup-guide-metadata-segments/relationships/); [arXiv API user manual](https://github.com/arXiv/arxiv-docs/blob/develop/source/help/api/user-manual.md). **Support:** direct evidence for the identifier/relationship schemes; inference for the gap to acquired-file labels. **Confidence:** high.

## Paper-disjoint feasibility and decision

| Source | Human labels relevant here | Paper-disjoint status |
|---|---|---|
| CEX | Manually annotated/corrected reference TEI paired with PDFs | Feasible by whole article/PDF only after file-level permission review; no supplied held-out split. Small per-field sample; group any duplicates before assignment. |
| GROBID evaluation | Publisher NLM/JATS reference gold paired with PDFs; not independent identity adjudication | Feasible by article directory, but first deduplicate/group bioRxiv/published versions; no supplied split. |
| Crossref 2,000 | Manually checked target DOI/null for references; no PDF | Feasible by `source_DOI`; no supplied split, and no extraction/asset coverage. |
| LinkedBooks | Human reference spans/fields from text lines | Feasible to regroup by source document IDs, but original split is not shown to be document-disjoint; source books/PDFs are not distributed. |
| RenoBench | Publisher JATS annotations, automatically extracted/matched | Only a custom split by non-null citing DOI; no PDF and no pre-defined held-out set. |
| DC3 | Manually checked same-work/version clusters | Cluster-disjoint split is feasible in principle; no official partition and reuse rights/snapshot are unresolved. |

**Decision:** no source satisfies issue #86 as-is. Crossref can be reused as a bounded DOI-matching benchmark (not as evidence for English-wide representativeness or file correctness); selected CEX PDFs can inform a bounded PDF-extraction benchmark only after their file-level reuse permissions are verified. For issue acceptance, these should be treated as component references or auxiliary tests, not stitched together and described as one representative gold set. A new set requires a declared sampling frame, per-paper source and target/version grouping, permissions for each input PDF and candidate asset, and explicit human adjudication of genuine reference vs artifact, correct vs false identity, and exact acquired permitted asset. Report unknowns rather than inferring labels; do not use missing DOI, missing relationship, or publisher XML as proof of no identity/asset.

## Contradictions

None found among the reviewed primary sources. Their labels differ in meaning: CEX/LinkedBooks label reference text/fields, Crossref labels DOI matches, and DC3 labels same-work clusters. Those are complementary evidence, not contradictory ground truths.

## Missing evidence

- No reviewed corpus labels the exact file bytes acquired by Paper T-Rail, permission/legal-location eligibility, or whether the acquisition was the correct version.
- No source provides supported denominators across the required English academic disciplines and all five source publication types (articles, conference papers, preprints, books, chapters). Where type percentages exist, they may describe cited items rather than citing papers.
- No external corpus can attribute this application's historical 14 unresolved / 25 metadata-only / 14 skipped records without the corresponding run inputs and provenance; this note does not inspect or download them.
- Crossref provides no reported human double-review/IAA or subgroup table for its 2,000-reference set. CEX's public record likewise does not report independent adjudication metrics. LinkedBooks explicitly reports no double-keyed subset.
- DC3's paper/repository do not establish an explicit data license in the inspected materials, and the underlying 2020 S2ORC snapshot is no longer the supported distribution.

## Next steps

For a user-adjudicated set, agree on the population/sampling frame and per-paper grouping before labeling. Preserve input and candidate-asset provenance/permission records, keep all versions of a source work within one split, and have reviewers separately record reference existence, target identity (including null/ambiguous/related-work cases), and exact acquired asset/version/license outcome. Reserve a locked held-out group and publish denominators plus unknowns. Existing sources can seed schema and bounded component tests; they do not justify calling the resulting set representative without an explicit sampling argument.
