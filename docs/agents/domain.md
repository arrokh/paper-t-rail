# Domain Docs

## Before exploring

- Read root `CONTEXT.md` for project vocabulary.
- Read relevant ADRs in `docs/adr/`.
- If either is absent, proceed without flagging it.

## Layout

This is a single-context repo: root `CONTEXT.md` and system-wide ADRs under `docs/adr/`.

## Use the glossary

Use terms as defined in `CONTEXT.md` in issue titles, proposals, hypotheses, and tests. Don’t substitute terms the glossary says to avoid.

## ADR conflicts

If work conflicts with an ADR, surface the conflict explicitly rather than silently overriding it.
