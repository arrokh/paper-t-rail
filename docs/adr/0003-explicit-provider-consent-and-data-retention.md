# Require Per-Run Provider Consent and Explicit Deletion

Providers must have a documented trust boundary and reviewed retention/deletion terms before enablement; unclassified and external providers are disabled by default. External providers may receive only the minimum necessary content with per-provider, per-run consent for stable, disclosed data categories. V1 retains local document data until the user explicitly deletes it, with no automatic expiry. Deletion first tombstones the document and invalidates pending work; workers check the tombstone before starting new provider calls and before committing results. Deletion removes document-scoped content and derived results, including per-run consent/configuration snapshots, while shared assets remain only if another non-deleted document/run references them. Local deletion cannot retract content already sent to a provider, so provider retention/deletion limitations must be disclosed. This favors user control and predictable local retention over implicit external sharing or surprising automatic data loss.
