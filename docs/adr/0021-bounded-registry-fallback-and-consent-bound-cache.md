# Use bounded registry fallback with consent-bound provenance

New opt-in scholarly discovery chains keep Crossref first and add DataCite for exact-DOI confirmation when Crossref cannot supply a usable record; a returned bibliographic conflict stops resolution rather than triggering a vote between providers. Version and pin the ordered selections, disclosures, operational budgets and effective configuration, preserving legacy single-provider snapshots and requiring each provider's explicit consent even on cache hits. Treat cached external metadata as originating-provider output: new-chain cache reuse needs the same consent/disclosure and compatible provider configuration, while provenance-less legacy entries are misses; this favors accountable identity and privacy over broader fuzzy search and maximum cache reuse ([approved contract](../research/issue-94-approved-provider-chain.md), [ADR 0020](0020-require-matching-consent-for-provider-output-reuse.md)).
