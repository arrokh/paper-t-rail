# Offer Crossref and Unpaywall options in the local default configuration

To make provider-consent and cited-paper acquisition flows testable from a fresh local setup, the repository enables Crossref and Unpaywall as catalog choices. API requests that omit either provider still fall back to recorded fixtures; the web new-run form initially prefers Crossref and Unpaywall when listed. The initial selection alone never makes an external request: matching per-run consent is required first. This supersedes ADR 0003's prior disabled-by-default rule only for these two catalog options. [ADR 0009](0009-configured-external-providers-with-per-run-consent.md) supersedes this decision's provider-terms-review prerequisite: provider terms are informational, not an enablement gate. Credentials remain deployment-specific and the disclosure must identify known terms or state when details are unknown.
