# Stage rights-declared recovery PDFs in a bounded, temporary batch

A Recovery Batch is a temporary user-supplied upload path attached to a non-deleted predecessor Analysis Run; it records the exact versioned rights declaration, does not mutate the immutable run, and does not begin provider assessment or establish identity, language eligibility, legal permission, or evidence support. The per-file cap inherits `paper-trail.upload.max-bytes`; the default batch cap is 10 PDFs and 250 MiB total, presigned PUT URLs last 5 minutes, and inactivity expires after 7 days since the last successful user mutation. Cleanup runs hourly, waits until URL expiry plus a 1-hour transfer grace, and retains content-free object-key tombstones for hourly retries for a further 7 days; a request already accepted by S3 cannot be revoked, so the finite retry horizon is explicit rather than a claim of an unbounded in-flight guarantee. Accepted Cited Paper Assets are promoted outside staging and are not subject to this expiry. The app owns the staging bucket's narrow CORS rule (configured exact browser origins, PUT only, `Content-Type` and SHA-256 checksum headers); this replaces the bucket CORS configuration and requires bucket CORS write permission. The recorded declaration is a user's assertion, not a license grant or external-provider consent.

## Consequences

- Direct uploads bind expected byte count, `application/pdf`, and SHA-256 in the signature. Finalization reads the actual bytes, checks size/hash and PDF structure locally, then writes a stable server-owned snapshot; later assessment must use that snapshot, not the writable staging key.
- The configured file-size limit stays aligned with Analysis Run PDF uploads while remaining overridable through `application.yml`.
- A removal immediately attempts deletion and retains a cleanup tombstone through the URL and retry windows so an in-flight or replayed PUT can be removed later. A stalled request that finishes after the bounded retry horizon remains a storage-service limitation and must not be described as impossible.
