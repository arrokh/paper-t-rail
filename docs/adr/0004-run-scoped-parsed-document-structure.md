# Persist Parsed Document Structure Per Analysis Run

GROBID output is persisted under its `Analysis Run`, not shared by `Source Document`. Keep the exact raw TEI response in private object storage at a run-scoped, content-hash-keyed path and persist that key with the parsed records. Every run pins a parser identity and version, and re-analysis must preserve earlier results even if the parser or extraction behavior changes. Parsed structures therefore store the run's source SHA-256, parser provenance, normalized text, sections, Citation Contexts, Citation Occurrences, Bibliography Entries, and occurrence-to-entry targets together as immutable run-scoped data.

The normalized source text is the whitespace-normalized text of the GROBID body sections in order, with one newline between sections and between paragraphs in a section. Section and citation spans are zero-based, end-exclusive UTF-16 code-unit offsets into that text, matching the Kotlin and browser string-indexing convention. GROBID TEI's citation-callout/reference links supply target identities. Context segmentation recognizes semicolons and explicit contrastive/subordinating connectors as clause boundaries; when no such boundary is reliable, markers stay within their containing sentence and the fallback kind is recorded.

The adapter explicitly submits `consolidateHeader=0` and `consolidateCitations=0` on every request. The default GROBID service runs on the private Compose network, and configured GROBID endpoints are restricted to localhost or trusted private-network addresses. Bibliographic consolidation remains unavailable in this slice; parsed bibliographic metadata is not sent to an external resolver.

The run enters `PARSED`, not `COMPLETED`, after this stage: no claim/evidence pairs exist yet, and `COMPLETED` remains reserved for a finished Evidence Coverage Report. This keeps each run reproducible, makes every displayed source span auditable against a stored normalized text, and prevents a later parser run from rewriting an earlier run's structure.
